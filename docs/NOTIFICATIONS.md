# การแจ้งเตือนหน้างาน

- เปิดเว็บค้างไว้ ระบบอ่าน Alert ทุก 15 วินาที หากเชื่อมต่อขาดจะแสดงข้อความพร้อมเวลาที่อัปเดตล่าสุด ไม่ใช่ระบบแจ้งเตือนเมื่อปิดเว็บหรือปิดเครื่อง
- กด **เปิดเสียงแจ้งเตือน** หนึ่งครั้งหลังเปิดหน้าเว็บ/เข้าสู่ระบบ เบราว์เซอร์ต้องได้รับการกดจากผู้ใช้ก่อนเล่นเสียง ถ้าเบราว์เซอร์พักระบบเสียง ปุ่มจะกลับมาให้เปิดเสียงอีกครั้ง
- ป๊อปอัพแสดงเคสสถานะ new ที่ยังไม่รับทราบ จัด high ก่อน warning และ info แสดงค่าอ่าน วันที่ข้อมูล และป้าย Demo ตามต้นทาง ไม่เปลี่ยนระดับความเร่งด่วนที่กฎส่งมา
- เสียงดังหนึ่งชุดต่อ Alert ใหม่ ไม่ดังซ้ำทุกการดึงข้อมูล รายการย้อนหลังที่ยัง new จะเปิดป๊อปอัพครั้งแรกแบบเงียบจนกว่าจะเปิดเสียง
- **รับทราบ** บันทึกเฉพาะเบราว์เซอร์และบัญชีนั้น ไม่ใช่การยืนยันว่าพบความผิดปกติ ไม่เปลี่ยนสถานะหรือผลตรวจของวิศวกร หากล้างข้อมูลเบราว์เซอร์จะเห็นป๊อปอัพเคส new อีกครั้ง
- กด **เปิดเคสเพื่อตรวจสอบ** เพื่ออ่านหลักฐานและบันทึกผลหน้างาน เคสที่อยู่ investigating, resolved หรือ false_positive จะไม่ถูกนำมาแจ้งซ้ำ
- กด **ทดสอบ** เพื่อทดลองหน้าต่างแจ้งเตือน ถ้าเปิดเสียงแล้วจะมีเสียงตัวอย่างด้วย ไม่สร้าง Alert หรือแก้ข้อมูลฐานข้อมูล
- เมื่อปิดป๊อปอัพด้วย Escape โดยยังไม่รับทราบ รายการยังอยู่ในแถบรอรับทราบ สามารถกดดูอีกครั้งได้

เสียงอาจไม่ได้ยินหากแท็บหรืออุปกรณ์ถูกปิดเสียง ตั้งระดับเสียงอุปกรณ์ให้เหมาะกับบริเวณใช้งาน ระบบนี้ไม่มีคำสั่งควบคุมหม้อไอน้ำ
